# Documentation

- `adr/` — architecture decision records, one file per decision.
- `design/` — the UI design: design system, screens and flows, keyboard map. The code side is `App/FA/DesignSystem/`.
- `compliance-checklist.md` — what each document type must contain under Czech VAT law, with paragraph references. The core's validators and tests follow this file.
- `setup-mac.md` — how to build and run the app on a Mac, and how updates work.

The full proposal (scope, phases, open questions) is the Claude Doc "Offline Mac invoicing app — architecture & MVP proposal", linked from the project thread.
